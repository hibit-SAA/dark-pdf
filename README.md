# 深色 PDF 阅读器 · Dark PDF

Edge 浏览器扩展（Manifest V3）。打开任意 PDF 链接时自动接管，用自带的深色阅读器显示：
**文档内容反色（白纸变深底、黑字变亮字），顶部控制栏与页面背景始终保持深色，整页深色。**

---

## 安装（Edge）

1. 打开 Edge，地址栏输入 `edge://extensions/` 回车
2. 打开左下角（或侧栏）的 **开发人员模式**
3. 点击 **加载解压缩的扩展**，选择本目录 `edge-dark-pdf`
4. 完成。之后点开任意 `.pdf` 链接就会自动进入深色阅读器

> 想读本机磁盘上的 PDF，需要在该扩展的「详细信息」里打开 **允许访问文件 URL**，
> 否则 `file:///.../xxx.pdf` 仍然会走浏览器原生阅读器。

---

## 使用

| 操作 | 说明 |
| --- | --- |
| 打开 PDF 链接 | 自动进入深色阅读器 |
| 点击扩展图标 | 弹出设置面板，可开关自动接管、调整反色强度、把当前页强制用深色打开 |
| 顶部工具栏 | 上一页 / 下一页、页码跳转、缩放、适合宽度、反色开关、下载原文件、用原生阅读器打开 |

快捷键：

| 按键 | 功能 |
| --- | --- |
| `←` / `→`、`PageUp` / `PageDown`、空格 | 翻页 |
| `+` / `-` | 放大 / 缩小 |
| `Ctrl + 滚轮` | 缩放（触控板双指缩放同样有效） |
| `0` | 适合宽度 |
| `i` | 反色开关 |
| `Home` / `End` | 跳到首页 / 末页 |

## 设置项

- **自动接管 PDF 链接**：关闭后所有 PDF 都走原生阅读器，扩展只在你点图标时生效
- **默认反色**：进入阅读器时是否自动反色（阅读器里按 `i` 也能临时切换）
- **反色强度**：50%–100%，100% 为完全反色；调低可以让图片不那么"负片"

设置保存在浏览器账号同步存储里，换设备也会同步。

---

## 实现要点

1. **不闪白**：用 `declarativeNetRequest` 动态规则，在 PDF 请求发出之前就把主框架导航
   重定向到 `viewer.html?file=<原始地址>`，不会先闪一下白色原生阅读器。
2. **兜底识别**：地址里没有 `.pdf`、但响应头是 `application/pdf` 的链接（例如
   `download?id=123`），用 `webRequest` 观察响应头后补一次跳转；
   带 `Content-Disposition: attachment` 的仍然按下载处理，不拦截。
3. **只反色文档**：反色作用在渲染 PDF 的 `<canvas>` 上（`filter: invert() hue-rotate(180deg)`），
   顶部工具栏、背景、滚动条都是 CSS 里的深色，不参与反色。
4. **按需渲染**：用 `IntersectionObserver` 只渲染进入视口附近的页面，几百页的文档也不卡。
5. **可退出**：工具栏最后一个按钮「用原生阅读器打开」会临时关闭接管 20 秒并跳回原始地址，
   不会出现重定向死循环。

PDF 渲染使用本地打包的 Mozilla **pdf.js 3.11.174**（含 cMaps 与标准字体），完全离线，
不上传任何文件，也不需要任何网络权限之外的访问。

## 目录结构

```
edge-dark-pdf/
├─ manifest.json         扩展清单（MV3）
├─ background.js         Service Worker：跳转规则、响应头兜底、原生打开
├─ viewer.html/css/js    深色阅读器（工具栏 + pdf.js 渲染 + 反色）
├─ popup.html/css/js     扩展图标弹出面板
├─ icons/                16/32/48/128 图标
└─ vendor/               pdf.js、pdf.worker.js、cmaps、standard_fonts
```

## 已知限制

- 阅读器是自绘的，暂不支持选中文字 / 复制文本（需要文本层，后续可加）
- PDF 表单、批注、目录侧栏暂不支持
- 需要登录态的 PDF 会带上 Cookie 请求；极少数防盗链严格的站点可能取不到文件，
  此时会提示「读取文件失败」，可以直接点「用原生阅读器打开」
- 加密（需要密码）的 PDF 会提示无法直接打开
