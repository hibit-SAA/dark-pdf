# 深色 PDF 阅读器 · Dark PDF（第二版：保留 Edge 原生工具栏）

Edge 浏览器扩展（Manifest V3）。打开 PDF 时，**完全保留 Edge 原生的 PDF 工具栏**
（页码、缩放、旋转、搜索、打印、绘图、Copilot…），只把文档画面反色成深色：
白纸变深底、黑字变亮字，页面背景保持深色。

> 第一版（自绘阅读器、整页全深色、但没有原生工具栏）已单独备份在 `../edge-dark-pdf-v1/`。

---

## 安装（Edge）

1. 打开 Edge，地址栏输入 `edge://extensions/` 回车
2. 打开左下角（或侧栏）的 **开发人员模式**
3. 点击 **加载解压缩的扩展**，选择本目录 `edge-dark-pdf`
4. 完成。之后点开任意 `.pdf` 链接就会自动变成深色

> 想读本机磁盘上的 PDF，需要在该扩展的「详细信息」里打开 **允许访问文件 URL**。

---

## 效果说明

- **工具栏**：原封不动。它是 Edge 自己画的，扩展不碰它，所有按钮和功能都在。
  颜色跟随浏览器主题——Edge 处于深色模式时它就是深色的。
- **文档画面**：反色显示（`invert + hue-rotate`），白纸变深底、黑字变亮字，彩色图片色相不跑偏。
- **页面外的空白**：和文档画面在同一层，会被一起反色成浅灰。
  - 想让整页全黑，打开设置里的「页面外空白也压深」；
  - 或者在原生工具栏里点一下「适合宽度」，页面铺满后空白就基本没有了。

## 设置（点扩展图标）

| 项目 | 说明 |
| --- | --- |
| 启用深色反色 | 总开关。关闭后 PDF 立刻恢复原始白色 |
| 反色强度 | 50%–100%，100% 为完全反色；调低会让图片不那么"负片" |
| 页面外空白也压深 | 用一条陡峭曲线把页面外的浅灰压成深色。**代价：图片、色块会变暗**，纯文字文档效果最好 |
| 重新应用到当前页 | 手动刷新一次（一般用不到，改设置会自动生效） |

## 实现要点

1. **为什么能改**：PDF 在浏览器里是一个「插件文档」（`<embed type="application/pdf">`），
   manifest 里声明的内容脚本进不去，但 `chrome.scripting.executeScript` 可以程序化注入。
2. **为什么工具栏还在**：工具栏和文档画面在同一个 `<embed>` 里。直接给 `embed` 加 `filter`
   会把工具栏一起反色成浅色。所以改成在**工具栏下方**盖一层
   `pointer-events: none` 的遮罩，用 `backdrop-filter` 反色它背后的画面——
   工具栏在遮罩之上，完全不受影响。
3. **为什么不闪白**：在 `tabs.onUpdated` 的 `loading` 阶段就注入，早于 PDF 渲染。
4. **为什么用固定 id 的 `<style>`**：关闭时能干净移除，不受 Service Worker 被回收、
   内存状态丢失的影响。
5. **无网络、无上传**：不加载任何远程资源，不需要 pdf.js，整个扩展不到 40 KB。

## 已知限制

- 页面外的空白和文档在同一层，反色必然一起变；这是浏览器渲染结构决定的
- 「压深」模式会牺牲图片/色块的层次（只保留接近纯白与纯黑的内容）
- 工具栏高度按 41px 计算（Edge 当前版本）。若某个版本工具栏变高，遮罩上沿可能露出
  一条细浅边——基本看不出来，但属于已知风险
- 加密（需要密码）的 PDF 仍会正常提示输密码，反色照常生效
